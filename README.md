## 🧑‍💻 Who Am I?

I'm **Yogesh Tiwari**, a student and aspiring developer who enjoys turning ideas into **interactive, visually engaging, and functional digital experiences**.

I don't like building interfaces that simply work.

I like building interfaces that **feel alive**.

My projects often combine:

- 🌐 Web development
- 🎨 UI/UX design
- ✨ Animation
- 🎮 Game-inspired interaction
- 🤖 AI experimentation
- 🧠 Programming logic
- 🚀 Real-world problem solving

I'm currently exploring how **web development, AI, and game development** can come together to create better digital experiences.

---

## ⚡ My Development Philosophy

> **Build it. Break it. Understand it. Improve it. Ship it.**

I learn best by creating real projects.

Instead of only following tutorials, I try to turn ideas into working applications, discover problems along the way, and use those problems as opportunities to understand the technology better.
